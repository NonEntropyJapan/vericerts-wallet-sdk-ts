# Security policy

## Supported version

We triage reports against the current `main` branch. Include the SDK version or commit you tested and whether the issue also affects `main`, if known.

## Report a vulnerability

Use GitHub's [private vulnerability report form](https://github.com/NonEntropyJapan/vericerts-wallet-sdk-ts/security/advisories/new). Keep vulnerability details out of public issues and pull requests.

Describe the impact, the affected SDK version and runtime, and the steps needed to reproduce the issue. Use synthetic inputs and remove credentials, signing keys, and personal data from anything you share.

The maintainers will use the private report to discuss the findings and coordinate disclosure.
