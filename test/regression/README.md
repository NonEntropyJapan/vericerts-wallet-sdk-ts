# `test/regression/` — L10 回帰テスト

過去に直した不具合の再発を防ぐ L10 回帰テストを置く。

## 命名規約

このディレクトリ配下の `*.test.ts` にある `it(...)` / `test(...)` の説明文字列は、必ず

```
regression: <何を保証するかの短い説明>
```

の形式で書く。テスト名には再発を防ぐ動作を記載する。

## 何をここに置くか

- 新規に発見・修正した bug の回帰テストは、原則としてこのディレクトリに新規ファイルとして追加する。
- 既存コードに同居している回帰テスト（`__tests__/` 配下に機能テストと混在しているもの）は、
  当該ファイルがバグ修正専用で自己完結している場合に限り、このディレクトリへ移行してよい。
  機能テストと不可分に混在しているものまで無理に移行する必要はない。

## ディレクトリ構成

対象ごとにサブディレクトリを切り、関連する複数の回帰（同一根本原因から派生した複数 Issue 等）は
まとめてよい。例: `signature-canonical/`（ECDSA 署名検証の正準性まわり）。
